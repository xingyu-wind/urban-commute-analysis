# T3-USB：知识关联与实现

联网引导包与离线包的区别在依赖取得方式：业务JAR、Vue产物、正式迁移和合成种子保持冻结；USB包额外携带锁定的官方归档、许可、源码和提供书。维护者可联网收集，目标配置只能读取包内vendor目录，缺件或错误SHA立即拒绝，不能悄悄降级为下载。

SHA256锁绑定“取得了哪个文件”，MANIFEST绑定“这个候选分发了哪些字节”，BUILD绑定业务与打包提交；三者服务不同的追溯问题，不等于供应链签名认证或法律授权。归档必须保留LICENSE/NOTICE与GPL源码交付条件。微软VC++属于系统前提，不能把网上可下载等同于有再分发权；本人直接取得的官方离线安装程序单独携带，权限与许可由操作者明确处理。

U盘是运输介质，本地NTFS才是运行存储。复制时只取清单中的静态文件，目标每安装自行初始化MySQL、V1–V6和账号；不搬开发数据库、密码或DPAPI。MySQL原生路径要求独立ASCII目录；便携并不意味着中文路径、C盘或企业权限策略一定可用。

随机账号、DPAPI、仅127.0.0.1、CSRF和角色授权共同保持运行边界。Windows Job把子进程生命周期绑定监管器；正常STOP请求MySQL正常关闭，崩溃时回收本轮子进程。USB新增的MySQL初始化进程也纳入Job，避免初始化监管器异常退出后留下专属子进程。

离线执行模式会拒绝Python监管器的非回环连接与外部DNS；这是应用级边界，不等于整台Windows已经断网。无法断网时必须分开报告“新目录、包内完整依赖配置成功”和“整机物理断网未验证”。同机测试也不等于新电脑或Windows10验证。

现场架构仍是浏览器→本地同源Python静态服务/代理→Java→MySQL；研究文件由Java调用独立Python桥接分析。Hadoop/Hive在既有离线链路运行，现场读取合法已发布合成快照；上传研究输入、训练、数仓发布是分开的步骤，不能讲成自动贯通或实时训练。T3.1 BLOCKED历史不因USB包装而被改写。
