# 前端重构知识关联与实现说明

Vue 页面由 `frontend/src/App.vue` 负责布局、五个导航入口及共享城市/数据集。这里使用浏览器 hash 表示页面，支持深链接、前进和后退，不额外引入路由框架。`ref` 保存选择和加载状态，`computed` 派生当前城市/数据集；统计组件在页面切换间保留筛选，城市/数据集变化时通过稳定 key 重建，避免上一城市结果残留。

`api/availability.ts` 校验 Java 元数据并把实际 UTC 首末观测时间转为最近七日半开日期窗口。`AvailabilityController` 严格解析 cityId，`AvailabilityRepository` 用参数化 SQL 在同一个只读快照内读取城市关联数据集、CITY/REGION/ROAD 各自范围及已发布模型截止日。原始记录范围与公开统计权限分别判断；simulation/mock/forecast 不会触发统计或预测查询。它只查询既有表，不改变 MySQL 迁移、观测、Hive 或模型发布指针。

`TrafficDashboard.vue` 调用原有四个统计接口，分别显示城市指标、序列、区域和道路；没有 REGION/ROAD 观测时显示空状态，不从 CITY 推算。每轮请求的版本号和卸载清理保证旧异步结果不能覆盖新选择。`TrafficChart.vue` 延续 ECharts SVG 渲染及 ResizeObserver，响应容器尺寸、清理监听与实例；日期、单位、双轴和表格与 API 含义对应。

`PredictionPanel.vue` 只读取已发布 MySQL 预测。历史 28 点与预测 7 点使用两个独立数组绘图，不补随机值，也不把截止日改成今天。前端契约校验要求预测日期逐日对应发布截止日；MAE/RMSE 属于已选模型的测试切分。版本和审计信息折叠展示，不删除底层记录。

`OperationsPanel.vue` 沿用 Cookie 会话、每次写操作取得 CSRF、ADMIN/READER 权限与人工映射确认。隐藏按钮只是体验优化，真正授权仍由 Java `SecurityConfig` 和业务校验决定。新增元数据仅将一个精确 GET/HEAD 路径加入公开读取清单，默认拒绝保持不变。

`style.css` 使用浅色与深色主题变量、CSS Grid 和媒体查询适配桌面/窄屏；大屏收起日期表单减少重复信息。浏览器测试会检查实际控件遮挡、横向溢出和 ECharts 尺寸。`verify_workbench_regression.py` 仅在本轮测试安装生成的新隔离库运行回归；Windows ZIP 继续复用原 T3-USB 的组件锁、源码包和逐文件哈希校验。
