## 数据库与 API 变更

数据库五表和两份 Flyway 迁移不变。新增经过运行验证的 `database/fixtures/s4-synthetic.sql`、独立 `s4-expected.sql`；fixture 不是迁移，不自动装载，重复 ID 直接失败。样本城市/两区域/两路段/9条观测均是 synthetic_test；只有东区带一个 WGS84 合成测试点，西区无坐标。

新增 `GET /api/v1/traffic/summary`、`series`、`regions`、`roads`。共同必填 cityId/from/to，datasetId 默认城市登记数据集。series 支持 hour/day；roads 支持同城 regionId、字面 search、page/pageSize。参数上限、错误、排序、完整空值约定见 [运行指南](../guides/s4-dashboard.md) 与 [OpenAPI](../../contracts/openapi.yaml)。

速度 km/h、指数0–10，按样本算术平均。UTC `[from,to)`，2000–2099年、最多毫秒精度、窗口≤366天（小时≤31天）。N=0 时均值和截至时间都是 null。dataAsOf 取所选数据集和层级范围的最大观测时间，不用请求时刻替代。道路 meta 的截至时间跨分页统计全部匹配观测。各 HTTP 响应为各自只读 repeatable-read 快照，不承诺四条请求跨接口同一事务。

允许 dev_seed/synthetic_test/historical_snapshot/authorized_live；排除 forecast/mock/simulation。SQL 全部参数绑定，固定枚举决定桶格式；关键词不成为 LIKE 通配符或 SQL 语句。未知、重复、非法参数和 GET 请求体均拒绝。
