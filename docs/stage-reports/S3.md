## 模型与契约
- 五表：`dataset_registry`、`city`、`region`、`road_segment`、`traffic_observation`。存在 FK、复合 FK、CHECK、唯一键、复合索引；维度/时间口径参见 `database/README.md`。
- Flyway V1 纯 DDL；不自动导入旧 ZIP、SQL 或 synthetic fixture。实例启动对 MySQL 有真实依赖；业务逻辑通过参数化 JDBC 查询，不再使用内存城市列表。
- `GET /health` 维持 S2 语义；`GET /api/v1/cities` 响应字段仍为 `id/name`，来源 meta 可以为 `synthetic_test` 或空库 `database_catalog`（混合目录 `mixed_catalog`）；`dataAsOf=null`，不伪造真实观测时间。
- OpenAPI/Java DTO/Vue 类型及前端来源标签同步；CORS/HTTP/异常处理保留。注意多数据集混合目录暂只给 `mixed_catalog`、不逐城市展开来源；S4 前需评审是否增加逐城市来源字段。

### 调试履历
- 第一轮真实 MySQL 8.4.11 已证实 `ck_obs_speed` 拒绝负车速，但 Spring JDBC 将该 CHECK 3819/HY000 包装为 `UncategorizedSQLException`；原测试错误地预期 `DataIntegrityViolationException`，导致 CI 红色。这是**测试期待值不正确**，并非 MySQL 未拒绝非法记录；随后在提交 `d2d1b361df4749060df56aa7199f2bb32e6c55dc` 修正断言后复跑。
- Flyway 日志有 `MySQL 8.4 newer ... support has not been tested; latest supported 8.1` 提示。迁移实测与官方兼容性声明不能混为一谈；这是需持续追踪的版本兼容风险。
