## WP2：OpenAPI 契约与静态自动化验证（已通过执行对话报告审核）

### 交付与设计

- `contracts/openapi.yaml`：OpenAPI 3.1.0 / JSON Schema Draft 2020-12；仅 `GET /health`、`GET /api/v1/cities`。
- 健康探针 HTTP 200 为 `status=UP` 与带时区时间戳，明确不使用业务封套；HTTP 503 使用统一错误响应。
- 城市成功 HTTP 200 为 `code=OK`、`message`、城市数组 `data`、`meta`；允许空数组，不允许成功 data 为 null。
- 城市 ID 为稳定字符串，meta 四字段全部必填：UUID requestId、dataAsOf=null、sourceType=dev_seed、datasetId=dev-seed-cities-v1。
- 定义 400/404/405/406/500/503 与业务 code 的一一映射。错误 data 与数据来源字段均显式为 null；405 要求 Allow 响应头。框架层错误及响应头需要后续真实 HTTP 测试。
- required 字段不能省略，未知字段不允许；空数组、空值、来源和固定示例时间的含义已写入契约及 README。
- 没有定义真实交通统计、MySQL、Hadoop/Hive 或机器学习接口，没有把开发样例伪装成实时数据。
