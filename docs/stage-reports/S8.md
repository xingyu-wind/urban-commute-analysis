## 接口与兼容性

| 接口 | 权限与语义 |
|---|---|
| GET `/api/v1/auth/csrf` | 匿名也可获取当前会话 token；不写入证据 |
| POST `/api/v1/auth/login` | form-urlencoded 账号密码 + CSRF；失败 401，成功更换会话 ID |
| GET `/api/v1/auth/me` | 已登录身份与 ADMIN/READER 角色；否则 401 |
| POST `/api/v1/auth/logout` | CSRF，失效会话并删除 Cookie |
| GET `/api/v1/operations/tasks` | ADMIN/READER；限定字段和最多 100 条各类任务，不返回原始文件或内部文档 |
| POST `/api/v1/operations/uploads` | ADMIN + CSRF；2 MiB CSV/平面 JSON、安全名称、实际解析、UUID 隔离保存 |
| POST `/api/v1/operations/imports/{id}/confirm` | ADMIN + CSRF；完整 review + 精确建议 SHA；会话操作者、确认时间、配置 SHA 不可改写 |
| POST `/api/v1/operations/imports/{id}/execute` | ADMIN + CSRF；确认必需、每个上传唯一任务、许可/质量/适用性复核 |
| POST `/api/v1/operations/imports/{id}/retry` | ADMIN + CSRF；仅 FAILED、总次数小于三，原任务状态比较更新抢占 |

原八个分析 GET 继续公开只读，旧响应结构与错误契约保留；对原只读路由的 POST 仍为原 405，CSRF 保护覆盖所有新增有副作用的 auth/operations 路径。开发仍为回环 Java/Vite 同源代理，无跨源凭证开放。HttpOnly、SameSite=Strict、仅 Cookie 会话、空闲20分钟；回环HTTP用 Secure=false，将来经授权 HTTPS 必须 true。

**运行管理的有意边界**：ETL/Hive/ML 复用原表和原受控 CLI，提供状态、错误码、批次和版本定位；没有任意命令、强制重试、训练或发布 API。只对确实适合重复执行的 S8 适配导入开放重试。S8 成功产物为隔离研究输入，不直接写 `traffic_observation`、`warehouse_current` 或 `prediction_current`，不改变已验收发布语义。原 CLI 任务没有补造 Web 操作者。
