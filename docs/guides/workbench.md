# 城市通勤工作台使用说明

无需登录即可浏览“总览首页”“交通分析”“智能预测”和“全屏大屏”。首页自动优先选择实际有观测或已发布预测的城市。城市下拉标签区分“统计 · 预测”“有统计数据”“有预测数据”“仅目录登记 · 暂无数据”；读取范围失败会单独提示并提供重试。simulation/mock/forecast 来源仅作目录登记，不能替代允许公开读取的观测或模型；即使底层有记录，也不会误报为可分析结果。

选择城市后，关联数据集同步更新。统计默认使用该城市、该数据集最近最多七日的有效观测范围，开始日包含、结束日不含，均为 UTC。改变日期自动查询；“最近有效时段”恢复元数据计算的窗口。切换分析入口保留日期筛选，切换城市或数据集重算范围。“刷新数据”重新读取目录及范围，恢复默认有效窗口。

“交通分析”提供速度/拥堵指数双轴趋势、小时或日粒度、缩放与 Tooltip、独立 REGION 对比、可用 WGS84 区域点位、ROAD 排名/关键词/分页和可展开趋势表。目录区域无观测时不绘制空图；点位图不表示道路底图，也不把城市数据当区域数据。

“智能预测”提供最近 28 日实际观测、已发布的七日预测、七个日期/数值、模型及 MAE/RMSE。“模型详情”保留完整版本、输入 SHA、训练时间、ETL 批次、来源哈希和回测。预测从该模型的数据截止日开始，历史快照不会自动变成今天的预测。“合成演示数据”不代表真实交通效果。

“全屏大屏”使用深色主题；点击“全屏 / 退出”可请求浏览器全屏，Esc 可退出。桌面默认收起统计日期表单，点击“调整统计时段”展开；窄屏按纵向排布。没有空间数据时保留明确说明，不画虚假地图。

“数据管理”才需要登录。ADMIN 上传 CSV/JSON 后核对建议，在完整审查 JSON 中明确字段、单位、时区、数据来源/用途与使用权；确认后才能执行隔离研究导入。READER 只能查看任务。成功导入不等于正式观测、训练或模型发布。Cookie 会话、CSRF、上传限制及服务端权限继续生效。

“交通分析”→“查看 Hive 数仓快照与同窗比较”读取已经发布的数仓结果。离线包的数仓演示沿用独立场景：先 STOP，再 START-WAREHOUSE，选择 s5-city；它不是现场执行 Hadoop/Hive。完整来源和限制可在“数据详情与使用边界”展开查看。

离线安装、账号查看和停止重启继续使用原 BAT 流程，见 [Windows USB 指南](windows-usb.md)。不得把 state、DPAPI 文件或已经初始化的 MySQL 数据跨机器迁移。
