# 初步系统架构

状态：规划，尚未实现。本文件不代表服务已启动或第三方资料中的功能已完成。

flowchart LR

数据源必须先核实许可、字段和质量。候选输入为道路速度、流量和拥堵相关数据，不假定拥有真实个人 OD 或通勤人数。代理指标的定义、时间粒度、区域范围及局限由 contracts 记录。

Python 清洗任务生成标准化输入；MySQL 规划承载结构化数据与查询结果，HDFS/Hive 规划承载历史分区数据及批量聚合。实际存储分工、同步策略和是否需要全套大数据组件，须根据数据规模评审。

## 离线任务

清洗、Hive 聚合、特征构建、训练和批量预测按批次执行，记录数据时间范围、版本、质量结果与任务状态。评估按时间划分训练和验证，避免未来信息泄漏。任务把统计与预测结果写入 MySQL；失败重试和幂等策略在实现阶段设计。

## 在线查询

Spring Boot API 按 contracts 查询已落库结果，Vue 展示趋势、统计和预测。用户查询不触发大规模清洗或训练；页面应显示数据更新时间、预测时间范围及代理指标含义。缓存、鉴权、分页和性能目标均待设计与验证。

当前只有文档骨架，没有数据库结构、任务代码、API 或页面实现。后续阶段依次确认契约和数据源、实现离线链路及在线服务，再开展联调与评估。
